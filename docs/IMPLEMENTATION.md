# Implementation report — Mastercraft Engineers redesign

Audit date: 2026-10-27. Everything below was done in this working copy; **nothing was deployed** and the production site was not modified.

## 1. Audit of the existing site

**Stack:** WordPress 5.2.21 (end-of-life) + WPBakery Page Builder + Slider Revolution 5.4.7.2, theme markup left over from a LearnDash course theme (an unused "Search Courses" form is in every page). No repository was supplied, so this is a separate implementation.

**Pages found (7):** `/`, `/facilities/`, `/components/`, `/injection-moulds/`, `/2k-parts/`, `/large-size-injection-moulds/`, `/contact/`.

**Strengths:** genuinely good, authentic photography (machining, CMM, MFI tester, moulding hall, mould/part pairs); real, specific technical data (17 large moulds, 7 small moulds, 18 components, 4 2K parts, machine strokes, clamping range); clean URL structure; a corporate YouTube video.

**Problems:** no meta descriptions; no XML sitemap (`/sitemap.xml` 404); robots.txt only disallows `wp-admin`; empty `alt` text on images; `href="#"` menu parents; home page has almost no copy; a hero "slider" with a placeholder image; "enter any two digits" spam field in the form; unoptimised JPEGs, no responsive images or modern formats; external Google Font and render-blocking WP/WPBakery assets; end-of-life CMS; no structured data; no "About", "Quality" or product-detail pages although the content existed.

**Content oddities to confirm with the client** (kept exactly as published, not "corrected"):
- *Housing Drive* mould: **4 t** for a 396 × 396 × 385 mm mould looks too heavy relative to the other moulds (possibly 0.4 t).
- 3-axis stroke is published as "**900 mm to 700 mm**"; the envelope diagram draws it as 900 × 700 mm and says so.
- Facilities states moulded parts of **0.5 ~ 300 g**, yet the components page lists a **0.11 g** clip frame.
- *Centre tube* group lists three parts but only two materials; the top cap shows no material.
- Several part names include the word "Hyundai" (*Cover/Housing Drive Hyundai*). The site does not claim any customer relationship and neither does the redesign; the word appears only inside the original part name. Decide whether to keep it.
- "SVG" in hot-runner entries is kept as written (not expanded).

## 2. Architecture decision
A **dependency-free static site** generated by a small Node build (`src/`), deployed as plain files, with one PHP file (`contact.php`) because the current host already runs PHP/WordPress. Rationale: content is small and stable; static output gives the best Core Web Vitals and eliminates the end-of-life WordPress attack surface; all URLs are preserved; no framework migration was needed. Motion uses CSS + ~9 KB (3 KB gzipped) of vanilla JS — no GSAP/Motion/Three.js, because nothing here needed them (no WebGL, so there is no WebGL failure path; the hero is a photograph with CSS/SVG layers).

## 3. Design system
- **Palette** taken from the logo: brand orange `#f18325` on near-black `#0b0c0e`, warm paper `#f2f0eb` for light sections; orange used sparingly (annotations, progress, CTAs). A darker orange (`#9c4300`) is used for text on light surfaces for contrast.
- **Type:** Archivo variable (width + weight axes) for headlines and text, IBM Plex Mono for technical labels/spec keys; self-hosted woff2, metric-matched fallback.
- **Grid & devices:** 12-column grid, hairline rules, corner crop marks and mono "FIG." captions as drafting cues; square corners (no card-heavy UI); each section has a distinct layout (sticky route, editorial grid, spec index, ruler, anatomy).
- **Logo:** the supplied wordmark; a light variant for dark backgrounds is generated by recolouring the black letterforms (orange mark untouched).
- **Motion system** (tokens at top of `main.css`): one easing (`cubic-bezier(.16,1,.3,1)`), durations 0.2 / 0.5 / 1 s, word-stagger 55 ms; transform/opacity/clip-path only. Hero: staggered headline, curtain + slow settle on the photo, SVG leader lines that draw, pulsing target dots, depth parallax (one rAF loop, runs only while the hero is visible). Sections: mask-reveals, SVG/stroke drawing for the envelope diagram and range rulers, process route that fills as you scroll, bars that grow, verified numbers that count up (final value is in the HTML), cross-document View Transitions between pages. `prefers-reduced-motion` removes all of it; content never depends on animation, and reveals only hide content after JS has started.

## 4. What was built
- **Pages (48 incl. 404/thank-you):** Home, About (new — company facts, vision, video facade), Facilities, Quality (new — CMM/MFI/SPC, glossary), four product listings, **37 product-detail pages generated from one template** (`detailPage`), Contact, Thank-you (noindex), 404.
- **Home:** hero with annotated real machining photo and tool-measurement inset → company story with design→mould→component strip → **sticky 7-stage manufacturing route** (project management, CAD, CAM, machining, assembly, injection moulding, inspection; the "inspection" track visibly links machining, moulding and inspection) → product showcase → quality → FAQ → enquiry CTA. Only stages supported by the old site are shown; "delivery" appears as a commitment in stage 1 because the old site gives no separate delivery stage.
- **Infographics (all SVG/CSS/HTML, keyboard accessible, with text equivalents):** process route; **mould anatomy** — real mould photo with 4 hotspots, labelling only what is visible; **machining envelopes drawn to scale** from published strokes with legend and table; **range rulers** for 45–150 t clamping and 0.5–300 g parts; **large-mould weight chart** (17 moulds, each bar a link) and full spec index table; materials list.
- **Navigation:** sticky, dropdown for Products implemented as link + disclosure button (works by click/keyboard/touch, not hover-only), `aria-current`, accessible full-screen mobile menu with focus trap/Escape, prominent "Discuss your project" CTA. The unused search form was dropped.
- **Contact:** labelled, validated form (client + server), inline errors with `aria-describedby`, live status region, honeypot + time trap instead of the digits field, prefill from product pages (`?ref=`), no-JS native POST fallback; address, both phone numbers, e-mail and a Maps *link* (no heavy map embed).

## 5. SEO / GEO / local
- Unique title + description + canonical per page, single H1, ordered headings; images have descriptive filenames, alt text, intrinsic dimensions, AVIF/WebP/JPEG `<picture>` with responsive `srcset`, lazy loading except the hero (preloaded, `fetchpriority=high`).
- `sitemap.xml` (46 URLs with image entries), `robots.txt`, `404.html`, noindex on the thank-you page, canonical host/HTTPS redirects and legacy-URL 301s/410s in `.htaccess`. All 7 old page URLs are unchanged.
- JSON-LD (parse-checked): `Organization`+`LocalBusiness` (verified name, address, two phones, e-mail, founding year 1992, logo, YouTube `sameAs`; **no** invented geo, hours, ratings, prices or reviews), `WebSite`, `WebPage`/`AboutPage`/`ContactPage`/`CollectionPage`, `ItemList` on listings, `BreadcrumbList`, `Product` on detail pages (specs as `additionalProperty`, no offers/price), `FAQPage` on the home page (matches visible text).
- **No `VideoObject`:** schema requires an upload date, which could not be verified (YouTube did not expose it). Add it once the date is confirmed.
- **GEO:** consistent entity facts everywhere (footer, About "at a glance" table, Contact, JSON-LD); concise factual copy; spec tables in crawlable HTML; FAQ answering real procurement questions only from published data; glossary (HRS, CMM, MFI, SPC, EDM, 2K); contextual internal links; no fabricated certifications, customers, testimonials or statistics (every number on the site is either quoted from the old site or computed from it, e.g. "17 moulds", "1.3 – 18.5 t").
- **`llms.txt` not added.** A search on 2026-10-27 found no confirmation from Google or OpenAI that they read it, and sources disagreed; it adds maintenance with no verified benefit. Revisit if a major provider documents support. No special AI-crawler directives were added either.
- **Keywords:** the brief's phrases and the site's own wording were used naturally (precision injection mould, Bengaluru/Bangalore, large injection moulds, plastic injection-moulded components, 2K parts, CMM/MFI/SPC). **No keyword-research tool was available, so demand and competitiveness are unverified.** No location-landing pages were created.
- Security/privacy: CSP via `<meta>`, YouTube loaded only on click from `youtube-nocookie.com`, no analytics/third-party scripts (the old site had none visible in its HTML; add consent-aware analytics if needed).

## 6. Tests executed and actual results
Run with `npm test` (build → static checks → browser tests). Final run after all fixes:

| Check | Result |
|---|---|
| Build | 48 pages, sitemap 46 URLs |
| Static checks (`scripts/check.mjs`) | **PASS** — 48 pages, ~1,780 internal links, 351 `<img>`: unique titles/descriptions, canonicals, one H1, no heading jumps, valid JSON-LD, no broken links/anchors/images, no duplicate ids, no orphans, sitemap matches pages. Warnings only for the two noindex utility pages' short descriptions |
| Browser tests (`scripts/e2e.mjs`) | **629 / 629 passed** — every page at 375 / 820 / 1440 px: status, no console errors/warnings, no horizontal overflow, no broken images; **axe-core WCAG 2.0–2.2 A/AA + best-practices: 0 violations** on 11 representative pages at desktop and mobile; mobile menu, Escape/focus return, dropdown by keyboard, process highlighting + sticky rail releasing, hotspot toggling, form validation/success/server validation/header-injection/honeypot/cross-origin rejection/GET 405, reduced motion, no-JS rendering, video not loaded until requested, trailing-slash redirect |
| Lighthouse (v-latest, headless Chromium, simulated mobile throttling; served with gzip like production) | Mobile: Performance **99**, Accessibility **100**, Best Practices **100**, SEO **100**; **LCP 1.8–2.2 s, CLS 0, TBT 0 ms** on home, facilities, contact, small/large listings and a detail page (home mobile LCP 2.2 s). Desktop home: 100 / 100 / 100 / 100, LCP 0.5 s. Page weight 150–260 KiB |

Notes on these numbers: they are **lab results from a local server**, not field data; **INP cannot be measured in the lab** (TBT 0 ms is a proxy) and must be checked in Search Console/CrUX after launch. Without gzip (PHP's dev server) the same mobile home page scored 95 with LCP 2.7–2.8 s because of simulated slow-network transfer of the 42 KB uncompressed CSS (9.6 KB gzipped) — make sure `mod_deflate` is active in production (`.htaccess` enables it).

Issues found and fixed during testing: pre-reveal image scale caused horizontal overflow on narrow screens; reveal clip-path on the observed element stopped IntersectionObserver from firing; colour contrast on dimmed process steps; redundant alt text in the gallery; an error message appearing on field blur shifted the Submit button so the click was lost (real bug — fixed); the same-origin check in `contact.php` mishandled non-default ports.

## 7. Not done / limitations / assumptions
- **Not deployed.** See `DEPLOY.md`. Email delivery from `contact.php` was tested only in dry-run (it logs instead of sending); verify real delivery on the host, and set SPF/DKIM.
- Third-party validators (Google Rich Results Test, Schema.org validator, WebPageTest, real-device testing, Safari/Firefox) were not run. Playwright tested Chromium only.
- No new photography or video was created. The hero uses the existing machining photo; the callouts name only visible features. Original images are mostly ≤1.5k px wide and a few are soft; the campus aerial is a video still. **Recommended new assets:** a high-resolution hero video or photo set of the machining floor, a mould-opening or CMM clip, and a transcript for the corporate video.
- Photo-derived captions (e.g. "Tool measurement", "Coolant delivery") are descriptive of what is visible; the owner should confirm the machine/equipment identities.
- The Google Business Profile, citations and other off-site entity signals are external actions not performed.
- Product detail pages are generated from the same published data as the listings (they add structure, cross-links and schema, not new facts). If Mastercraft prefers not to have 38 near-template pages indexed, set `noindex` in `detailPage` or drop them from the sitemap.
- The brand wordmark PNG is low resolution (666 px wide); an SVG logo from the client would be sharper.
